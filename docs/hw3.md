Домашнее задание \
Авторизация \
Цель: Авторизация с использованием токенов

Описание/Пошаговая инструкция выполнения домашнего задания: 
1. Продумать RBAC-модель для проекта 
2. Настроить компонент Security 
3. Настроить авторизацию действий в контроллерах 
4. Настроить работу с токенами 

Критерии оценки: \
Для получения зачёта (6 баллов) работа должна удовлетворять следующим условиям:
1. Присутствует RBAC-модель с необходимым количеством ролей для проекта (т.е. у каждой бизнес-роли должна быть роль в \
RBAC-модели + роль администратора) 
2. Настроен доступ к контроллерам через компонент Security 
3. Пользователь авторизуется с помощью токена 

Дополнительно можно реализовать (+2 балла за каждый пункт): 
1. JWT-токены 
2. Раздельная конфигурация Security для разных окружений (например, отдельная роль для тестирования в dev-окружении). 
Смысл раздельной конфигурации должен быть обоснован, просто сделать две минимально отличающиеся конфигурации недостаточно
