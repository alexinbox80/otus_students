Домашнее задание \
Deployment

Цель: \
Доставка кода до production-окружения

Описание/Пошаговая инструкция выполнения домашнего задания:
1. Разработать пайплайн развёртывания приложения
2. Организовать автоматическую выкатку приложения с использованием инструментоа автоматического развёртывания

Критерии оценки: \
Для получения зачёта (6 баллов) работа должна удовлетворять следующим требованиям:

1. Пайплайн развёртывания учитывает все основные шаги (миграции, очистка и прогрев кэша, установка пакетов и т.п.)
2. Пайплайн развёртывает код на продакшен с нуля 

Дополнительные задания:
1. Вариант пайплайна для обновления существующего кода (+1 балл)
2. Пайплайн развёртывания на staging-окружение с прогоном unit-тестов (+1 балл)
3. Интеграционные тесты на staging-окружении (+1 балл)
4. Системные и end-to-end тесты в production-окружении (+1 балл)
