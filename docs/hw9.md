Домашнее задание \
Используем DDD

Цель: \
Использовать на практике элементы DDD в приложении

Описание/Пошаговая инструкция выполнения домашнего задания: \
Необходимо использовать элементы DDD из следующего списка в своём приложении:

1. Symfony Messenger
2. Раздельный маппинг и классы сущностей
3. ValueObjects и Агрегаты
4. CQRS
5. Разделение на слои (не обязательно всё приводить в соответствие разделению, достаточно организовать один правильно разделённый домен)

Критерии оценки: \
Для зачёта (7 баллов) работа должна удовлетворять следующим критериям:

1. В работе присутствует хотя бы 2 любых элемента DDD.
2. При реализации более 2 элементов за каждый следующий элемент +1 балл.
