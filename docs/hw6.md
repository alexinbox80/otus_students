Домашнее задание \
Покрытие unit- и интеграционными тестами основной бизнес-логики приложения

Цель:
1. определяем основную бизнес-логику приложения
2. покрываем unit-тестами основные пользовательские сценарии
3. покрываем интеграционными тестами основные бизнес-процессы

Описание/Пошаговая инструкция выполнения домашнего задания:
1. определяем основную бизнес-логику приложения
2. покрываем unit-тестами основные пользовательские сценарии
3. покрываем интеграционными тестами основные бизнес-процессы

Критерии оценки: \
Для получения зачёта (6 баллов) работа должна удовлетворять следующим требованиям:

1. Присутствует покрытие пользовательских сценариев unit-тестами
2. Должны присутствовать как тесты, валидирующие функционал, так и тесты, направленные на поиск ошибок
3. При отборе основных сценариев важно отобрать и те, где ошибка потенциально возможна (пользователь ошибся во входных \
данных), и реакция на эту ошибку может быть адекватной (не падаем с исключением, а пытаемся корректно обработать)

Дополнительные задания:
4. Покрытие интеграционными тестами основных бизнес-процессов (+2 балла)
5. Системные или end-to-end-тесты на основные бизнес-процессы (+2 балла)
