Домашнее задание \
Декомпозируем приложение

Цель: \
Выделить часть функционала в отдельный конфигурируемый Bundle

Описание/Пошаговая инструкция выполнения домашнего задания: \
Выделить часть реализованного функционала в отдельный конфигурируемый Bundle. \
При вынесении можно добавлять функционал, необязательно брать только то, что было реализовано, \
также можно реализовать полностью новый функционал в отдельном бандле, но при этом важно, чтобы \
у него была связь с приложением, а не просто отдельная ненужная логика.

Критерии оценки: \
Для зачёта (6 баллов) работа должна удовлетворять следующим критериям:

Функционал вынесен в отдельный Bundle. В бандле присутствует конфигурация, которая упрощает настройку \
(если для настройки бандла нужно написать больше кода, чем изначально было необходимо без бандла, то этого \
недостаточно). Бандл установлен через composer и подключен.

Дополнительные задания:
1. Конфиг бандла позволяет конфигурировать другие бандлы (например, Doctrine или rabbitmq-bundle) (+2 балла)
2. Бандл содержит отдельные конфиги для различных окружений (например, для тестирования предоставляются dummy-сервисы) (+2 балла)
