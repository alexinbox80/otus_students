Домашнее задание \
Использование GraphQL 

Цель: \
GraphQL с помощью API Platform

Описание/Пошаговая инструкция выполнения домашнего задания: \
Подготовить REST и GraphQL API с помощью API Platform для нескольких сущностей бизнес-логики

Критерии оценки: \
Для зачёта (6 баллов) работа должна удовлетворять следующим критериям:

В работе присутствует REST и GraphQL API для пары связанных сущностей. Есть возможность запросить с помощью GraphQL \
"родительскую" сущность и её "дочерние" сущности

Дополнительные задания:
1. В REST/GraphQL запросах можно использовать фильтрацию по значениям полей (+1 балл)
2. В REST/GraphQL запросах можно использовать сортировку (+1 балл)
3. В GraphQL корректно работают мутаторы (+1 балл)
4. Для GraphQL реализован кастомный резолвер коллекций с фильтрацией (+1 балл)
5. Инвалидация кэша через асинхронный подход (+1 балл)
