Домашнее задание \
Интеграция с внешними системами

Цель: \
Интеграция с RabbitMQ, Memcached/Redis

Описание/Пошаговая инструкция выполнения домашнего задания: \
Настроить кэширование для наиболее критичных по производительности запросов \
Настроить асинхронную обработку длительных бизнес-процессов

Критерии оценки: \
Для получения зачёта (7 баллов) работа должна удовлетворять следующим критериям:

1. Для обработки длительных бизнес-процессов используется асинхронный подход с использованием RabbitMQ \
Дополнительные задания:
2. Настроить кэширование с помощью Memcached/Redis для наиболее критичных по производительности запросов (+1 балл)
3. Интеллектуальная инвалидация кэша (если в проекте есть возможность более сложной логики, чем "протухание" по TTL) (+1 балл)
4. Инвалидация кэша через асинхронный подход (+1 балл)

В проекте реализовано:
- асинхронное уведомление студента через почту о полученном балле за задание
- асинхронное направление кода подтверждения для почты и телефона студенту и преподавателю
- расчет баллов полученных студентом

- кэширование моделей CompletedTask, Skill, Student, Teacher, StudentGrade
- инвалидация кэшей моделей при изменении полей, создании и удалении сущностей
